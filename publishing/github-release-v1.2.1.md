Signed karma **100 or higher** now grants **Hero of the Village I**, including while untransformed.

The reward renews while eligible. Below 100 or with karma disabled, it expires within 200 game ticks (10 seconds at normal speed). Existing longer, stronger, or infinite Hero effects are never shortened, downgraded, or forcibly removed. Dead and spectator players do not gain this reward.

Existing karma data, animal neutrality, and normal/evil Rider Power behavior remain unchanged. The threshold is fixed at 100 even with a customized score limit.

Install `krc-rider-power-1.2.1.jar` on both client and server. Requires Minecraft 1.21.1, Java 21, NeoForge, and KRC with its dependencies. Existing configuration and save data can be retained; the payload protocol remains version 2.

MIT licensed. Sources and CurseForge submission materials are included as separate downloads.

Validation: 12 JUnit tests and all 24 NeoForge GameTests passed with KRC 1.1.3 and 1.1.4. This release uses the verified KRC 1.1.4 dependency pin.

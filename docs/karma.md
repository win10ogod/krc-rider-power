# 騎士之力：善惡系統

從 1.2.0 起，玩家的功德與業力決定使用「騎士之力」或「邪惡騎士之力」。行善增強整體加成；業力越高，傷害越強、最大生命越低。同時只生效一種力量，所有騎士與符合共用變身介面的未來形態使用相同規則。

## 哪些行為記分

| 行為 | 預設變化 | 條件 |
| --- | --- | --- |
| 救治殭屍村民 | +10 | 成功完成救治、符合生成條件，且不是村民遭感染而來的目標 |
| 擊殺敵對怪物 | +1 | Minecraft／模組標記為 `Enemy` 的怪物，且符合生成條件 |
| 殺害村民、流浪商人 | −20 | 玩家造成或遊戲仍將死亡歸因於玩家 |
| 動物，包含馴養動物 | 0 | 不列入善惡判定 |
| PVP、其他生物、一般生存行為 | 0 | 不列入善惡判定 |

行為在未變身時也會記分。騎士之力仍只在完成 KRC 變身時提供加成。新玩家從 0 分開始，不追溯安裝前的行為。既有 1.1.0 善惡存檔直接沿用。

「敵對怪物」依遊戲類型判定，不檢查當下是否正在攻擊：例如終界使者也屬於 `Enemy`。近戰、箭矢及能歸因於玩家的 KRC 技能可以記分；環境死亡只有在遊戲仍保存玩家擊殺歸屬時才計入。寵物自行攻擊、模組假玩家自動擊殺不獲得分數。

救治完成時，分數歸給餵食金蘋果並啟動該次救治的玩家；完成時玩家離線也會記錄。中途死亡或尚未完成救治不加分。

## 功德、業力與兩種力量

存檔仍使用 −100～+100 的善惡值：`功德 = max(善惡值, 0)`、`業力 = max(-善惡值, 0)`。例如善惡 −100 就是業力 100；善惡 +100 是功德 100。兩者是同一分數的不同顯示，不另外累積兩份進度。

善惡值小於 0 時使用「邪惡騎士之力」；0 或正值使用「騎士之力」。從業力狀態行善，會先抵銷業力，再累積功德。停用善惡系統後一律使用共用基礎的騎士之力，歷史分數保留。

使用預設設定時：

| 善惡值 | 顯示 | 力量 | 傷害倍率 | 最大生命倍率 | 額外護甲 | 移速倍率 |
| --- | --- | --- | --- | --- | --- | --- |
| −100 | 業力 100 | 邪惡騎士之力 | ×2.5 | ×0.5 | +0 | ×1 |
| −50 | 業力 50 | 邪惡騎士之力 | ×2 | ×1 | +2 | ×1.075 |
| 0 | 中立 | 騎士之力 | ×1.5 | ×1.5 | +4 | ×1.15 |
| +50 | 功德 50 | 騎士之力 | ×1.75 | ×1.75 | +6 | ×1.225 |
| +100 | 功德 100 | 騎士之力 | ×2 | ×2 | +8 | ×1.3 |

邪惡路線以最大生命換取更強的傷害，護甲、韌性、移速和抗擊退的額外加成仍隨負向善惡值減少。沒有其他生命修飾值時，20 點原始生命在中立為 30 點、功德 100 為 40 點、業力 100 為 10 點。

### 計算方式

正向或中立時維持原本公式：

```text
加成強度 = 1 + 善惡值 / scoreLimit
傷害與生命倍率 = 1 + (基礎倍率 - 1) × 加成強度
```

負向時改用：

```text
業力比例 = 業力 / scoreLimit
傷害加成強度 = 1 + (evilDamageBonusScale - 1) × 業力比例
傷害倍率 = 1 + (attackMultiplier - 1) × 傷害加成強度
最大生命倍率 = healthMultiplier × (1 - 業力比例) + evilHealthMultiplier × 業力比例
```

`evilDamageBonusScale: 3` 表示最高業力將基礎的「額外傷害」乘三：預設基礎 ×1.5 的額外部分為 0.5，因此結果是 `1 + 0.5 × 3 = 2.5`。若管理員把基礎傷害設成 ×1，沒有額外傷害可放大，邪惡路線也維持 ×1。

其他四項數值兩種路線都沿用 `加成強度 = 1 + 善惡值 / scoreLimit`；加值乘以此強度，移速倍率為 `1 + (speedMultiplier - 1) × 加成強度`。停用善惡時此強度固定為 1。

兩種效果使用不同名稱與圖示，但伺服器只保留符合分數的一個等級 I 效果，共用固定屬性識別碼。KRC、裝備和其他模組的修飾值仍保留；邪惡生命倍率會縮放最大生命總值，Minecraft 屬性上下限照常適用。

力量切換保留目前血量百分比：例如受傷狀態從中立的 `12/30` 變成最高業力的 `4/10`，再變成最高功德的 `16/40`，都是 40% 血量。這是最大生命的取捨，不是持續扣血；登出、解除變身或停用時也不會補滿血。

## 防止反覆刷分

- 每位玩家每 24,000 個伺服器遊戲 tick 共用 30 點正分額度；救治與殺怪使用同一額度。20 TPS 下為 20 分鐘，伺服器停機或世界暫停不計時，低 TPS 會延長實際時間。
- 計時使用主世界的遊戲時間，不受睡覺、`/time set` 等日夜時間操作影響。這是每位玩家持久保存的額度窗口，不是現實午夜重置。
- 作惡不受正分額度限制，也不會補回已使用的正分額度。達到分數上下限後不再超出；獎勵只使用實際增加的分數額度。
- 一般生怪磚、生怪蛋、指令、發射器、怪物召喚及繁殖來源不給正分。試煉生怪磚仍可記分。模組未提供生成來源的目標可計分，仍受額度限制。
- 被排除的生成來源轉化成其他生物或史萊姆分裂後仍被排除，標記會保存到實體資料。
- 村民遭感染產生的殭屍村民不提供救治獎勵，第一次感染也適用；同一救治事件與反覆感染救治不能重複領分。這也表示自然遭殭屍感染的原有村民不會提供救治分數。
- 殺害村民的扣分不因其生成來源而豁免。死亡事件按目標記錄一次；已取消的死亡事件不記分。

自然生成的刷怪場仍可在正分額度內獲得分數；本模組不辨識地形是否為玩家建造的刷怪設施。管理員可調整分數與額度，或把 `hostileKillReward` 設為 0 停用殺怪獎勵。

## 管理員設定

首次啟動產生 `config/krcboost-karma.json`：

```json
{
  "enabled": true,
  "scoreLimit": 100,
  "cureReward": 10,
  "hostileKillReward": 1,
  "villagerKillPenalty": 20,
  "dailyRewardLimit": 30,
  "evilDamageBonusScale": 3.0,
  "evilHealthMultiplier": 0.5
}
```

| 欄位 | 意義 |
| --- | --- |
| `enabled` | 是否記分並依善惡縮放 Buff；`false` 保留紀錄並恢復共用基礎加成 |
| `scoreLimit` | 分數正負界限，必須是至少 1 的整數 |
| `cureReward` | 符合條件的救治完成獎勵 |
| `hostileKillReward` | 符合條件的敵對怪物擊殺獎勵 |
| `villagerKillPenalty` | 殺害村民或流浪商人的扣分，填正數表示扣除多少分 |
| `dailyRewardLimit` | 每 24,000 tick 的正分額度；0 表示不給正分 |
| `evilDamageBonusScale` | 最高業力時，基礎額外傷害的放大倍數；有限數字且至少 1，預設 3 |
| `evilHealthMultiplier` | 最高業力時的最大生命倍率；大於 0 且不超過 1，預設 0.5 |

事件獎勵、扣分量與額度需為非負整數，`scoreLimit` 至少為 1。既有設定檔不需要刪除；缺少的兩個新欄位會使用上述預設值，管理員可自行加入欄位修改。修改後由權限等級 2 的管理員或主控台執行 `/krcboost reload`；會一起載入善惡規則和 `config/krcboost.json` 中的六項基礎數值。無效設定會拒絕載入並保留先前有效設定，原檔不被覆寫。遊戲內編輯器修改共用基礎值，善惡規則透過上述檔案修改。

停用善惡期間，行為不改變分數；救治與生成排除標記仍會保存，重新啟用不能重複領取舊救治的獎勵。若縮小 `scoreLimit`，生效分數先按新界限計算，下次記分時將結果保存；停用本身不清除歷史。

## 查看與保存

- `/krcboost karma`：查看善惡分數、功德、業力、力量種類、傷害／最大生命倍率與主要規則。
- `/krcboost status`：查看共用基礎值、自己是否完成變身，以及個人的力量與倍率。
- 分數與正分額度按 UUID 保存於世界的 `data/krcboost_karma.dat`，跨維度共用；死亡、重生、登出或伺服器正常重啟不會重置。
- 普通玩家不能自行修改分數。沒有改分指令，也不接受客戶端傳入的善惡值。備份世界時請一併保留該資料檔。

Minecraft 1.21.1 的村民聲望與村莊英雄效果不是統一的玩家善惡系統；檢查 KRC 1.1.3 的屬性與玩家附加資料也未找到可直接沿用的善惡值。本模組使用自己的紀錄，不改寫原版村民聲望。
